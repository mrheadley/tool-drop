01 PRINCIPLE // Equilibrium & Weight

Balance: Symmetrical vs Asymmetrical

Balance distributes visual weight across a design so no single part feels overly heavy or unstable. Weight is influenced by element size, dark values, color saturation, and density.

Symmetrical Balance Elements mirror across a central axis. Creates formal, calm, elegant stability.
Asymmetrical Balance Unmatched elements offset each other by size/color. Creates energetic, modern compositions.

02 PRINCIPLE // Visual Impact & Focus

Contrast: Establishing Focus

Contrast occurs when two opposing elements are placed together. It commands instant user attention, creates focus, and ensures screen accessibility.

Dimensions of Contrast: Contrast isn't just color! It works through differences in Scale (huge vs tiny), Weight (bold vs thin), Shape (circle vs square), and Space.
Accessibility Standard (WCAG): High contrast ensures text remains readable for users with visual impairments or on bright phone screens.

03 PRINCIPLE // Grid & Visual Order

Alignment: Connection & Order

Alignment connects visual elements along invisible axes. Every element on screen should have a deliberate spatial relationship with other elements.

  • ✓ Edge Alignment: Left-aligned text aligns perfectly to a vertical grid, creating clean reading paths.
  • ✓ Eliminates Randomness: Prevents elements from looking accidentally scattered.
  • ✓ Grid Systems: Professional UI uses 4, 8, or 12-column grid systems for structured layouts.

04 PRINCIPLE // Cohesion & Rhythm

Repetition: Visual Cohesion

Repetition reuses visual elements—fonts, colors, border styles, icon sets, and spacing—throughout a project. Like the chorus of a song, repetition reinforces identity and builds user familiarity.

Design Systems: Frameworks like Material Design rely on strict repetition of radii, typography scales, and button elevation.

Mental Models: Consistent buttons tell users: "If it looks like a card, it will behave like a card."

05 PRINCIPLE // Spatial Relationships

Proximity: Grouping Related Items

The Gestalt law of proximity states that objects placed near each other are perceived as a unified group. Distance signals difference; closeness signals relationship.

● Form Labels & Inputs: Keep labels tight to their corresponding text input fields.
● Card Containers: Group image, title, and button inside a single enclosed boundary.

06 PRINCIPLE // Visual Dominance

Visual Hierarchy: Directing Attention

Hierarchy guides the viewer’s eyes through content in order of importance. Without clear hierarchy, every element competes for attention at once, overwhelming the user.

1. Scale / Size Large elements get scanned first.
2. Color / Weight Vibrant & bold elements pop out.
